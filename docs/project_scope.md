# Part A — Project Scope

## Application
Identification of Asali (genuine) or Nakali (counterfeit/unverified) medicine items at purchase time by integrating heterogeneous information from multiple independently maintained structured data sources.

## Required information domains from the project brief
1. Item unique code and item description.
2. Distributor/supplier details and items distributed to vendors.
3. Manufacturer/company item details with the unique code.
4. Reporting a Nakali item to the Ministry of Consumer Affairs.

The Part A implementation focuses on traditional structured-data integration. More advanced uncertainty-oriented reasoning is deliberately left for later project parts.
